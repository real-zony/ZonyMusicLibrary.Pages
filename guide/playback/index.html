播放

播放条在窗口底部，播放曲目文件里的真实音频，从系统默认的输出设备出声。

能播放的格式

链接到“能播放的格式”这一节

flac、mp3、wav，以及编码为 AAC 或 ALAC 的 m4a，都能正确播放。资料库识别的其余音频格式，解码器支持的照常播放；打不开的曲目会被跳过，接着放下一首。

播放条

链接到“播放条”这一节
  • 播放键在播放和暂停之间切换；按 空格 也一样，不管焦点在哪里（文字输入框和打开的右键菜单除外）。
  • 拖动进度推子跳到松开的位置；暂停时跳转只改变位置，不开始播放。
  • 音量推子推到最右时，输出的电平和文件里一致，不放大也不衰减。
  • 左右两排电平灯跟随正在播放的声音，越响亮的灯越多，最后 2 盏红灯只在接近满幅时亮。暂停时全部熄灭。

下一首和上一首

链接到“下一首和上一首”这一节

下一首和上一首按播放是从哪里开始的来走：

从哪里开始播放 下一首
专辑卡、专辑详情 这张专辑里的下一首；专辑放完后，接专辑页当前排序的下一张专辑
资料库页的歌曲列表 开始播放那一刻列表里的下一首，最后一首之后回到第一首

当前这首已经播放超过 3 秒时，“上一首”回到这首的开头。随机打开时，下一首在同一个来源里随机选；循环打开时，一首放完从头再放这一首。不能播放的曲目会被跳过。

输出设备

链接到“输出设备”这一节

拔掉耳机这类默认输出设备的变化，播放会改从新的设备继续。没有可用的输出设备时，播放条停在暂停状态，不报错。

在 macOS 上，输出设备支持曲目的采样率时，应用先把设备切到这个采样率再出声；音量推到最右时，16 位和 24 位的立体声无损曲目原样交给系统，不重采样、不改变增益。

系统的媒体控制

链接到“系统的媒体控制”这一节

在 macOS 上，开始播放以后，控制中心和锁屏的“正在播放”会显示当前曲目，键盘的媒体键、耳机线控和 AirPods 的按键都能控制播放。在 Windows 和 Linux 上，应用这一版还不接入系统的媒体控制。
