设置

设置页把应用的偏好分组列出，改动立刻生效，没有保存键，下次启动沿用。点侧栏底部的“设置”，或者按 ⌘ ,（Windows、Linux 上是 Ctrl ,）打开。

外观

链接到“外观”这一节
设置 选项 说明
主题 浅色、深色、跟随系统 默认浅色。选“跟随系统”时，系统切换外观后应用跟着切换
减少动效 拨动开关 没有拨过时跟随系统设置。打开后关闭位移、缩放、翻面和循环动画，状态变化只做短暂的淡入淡出

刮削

链接到“刮削”这一节

这一组的改动只影响之后的匹配和写入，已经写入的内容不会移动。

设置 选项 说明
歌词写到 文件标签、.lrc 文件 选 .lrc 文件时，在曲目旁边存一个同名的 .lrc
封面写到 文件标签、cover.jpg 选 cover.jpg 时，存在专辑所在的每个文件夹里
翻译歌词 不要、合成一行、分成两行、只要翻译 来源带翻译时怎样写，默认合成一行；没有翻译时只写原文
替换已有歌词 拨动开关 打开后，已有歌词的曲目也重新匹配；撤销时恢复原来的歌词
歌词文件编码 UTF-8、UTF-8 BOM、GBK 只对 .lrc 文件起作用。GBK 写不出的字符改用 UTF-8 保存
歌词来源 可排序列表 从上往下依次查找，关掉的来源不查
文件名格式 输入框 标签里没有标题时，按这个格式从文件名读出标题和艺术家

歌词来源

链接到“歌词来源”这一节

四个来源默认全部打开，顺序是网易云音乐、QQ 音乐、酷狗音乐、酷我音乐。拖动把手，或者聚焦一行后按 ⌥ ↑ / ⌥ ↓（Windows、Linux 上是 Alt ↑ / Alt ↓）调整顺序。

文件名格式

链接到“文件名格式”这一节

默认格式是 {艺术家} - {标题}。可以用 {艺术家}、{标题}、{音轨号} 三个占位，其余文字原样匹配。输入框下面实时显示一个例子，例如“中央乐团合唱团 - 好朋友 → 艺术家 中央乐团合唱团，标题 好朋友”；格式不合法时说明原因，并继续按上一次的格式读取。旁边预置了几组常用格式，点一下就能填进去。
