Install

ZonyMusicLibrary is a desktop app. The same code runs on Windows, macOS and Linux. Its fonts ship with the app, so it does not depend on what is installed on the system.

Caution

There are no installers yet. The steps below run the app from source.

What you need

Link to the “What you need” section
  • The .NET 10 SDK (any 10.0.x version)
  • The app’s source repository

Try the sample data first

Link to the “Try the sample data first” section

If you have no music folder ready, start with the sample data. It has 96 albums, never reads or writes the library or the settings file, and the play bar is simulated, so it makes no sound.
