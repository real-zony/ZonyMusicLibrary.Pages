Settings

The settings page lists the app’s preferences in groups. Changes apply at once and are kept for the next start; there is no save key. Open it with “Settings” at the bottom of the sidebar, or with ⌘ , (Ctrl , on Windows and Linux).

Appearance

Link to the “Appearance” section
Setting Options Notes
Theme Light, dark, follow the system Light by default. With “follow the system”, the app changes when the system’s appearance does
Reduce motion Switch Follows the system until you change it. When on, movement, scaling, flips and looping animations stop; changes of state only fade briefly

Covers and lyrics

Link to the “Covers and lyrics” section

Changes in this group affect only later matching and writing; what has been written stays where it is.

Setting Options Notes
Write lyrics to File tags, .lrc file With .lrc file, a .lrc with the same name is saved next to the track
Write covers to File tags, cover.jpg With cover.jpg, one is saved in every folder the album is in
Translated lyrics None, one line, two lines, translation only How a source’s translation is written; one line by default. Without a translation, only the original is written
Replace existing lyrics Switch When on, tracks that already have lyrics are matched too; undo brings the old lyrics back
Lyrics file encoding UTF-8, UTF-8 BOM, GBK Applies to .lrc files only. Characters GBK cannot hold are saved as UTF-8 instead
Lyric sources Sortable list Tried from the top down; switched-off sources are skipped
File name pattern Text field When a track’s tags have no title, the title and artist are read from the file name with this pattern

Lyric sources

Link to the “Lyric sources” section

All four sources are on by default, in this order: NetEase Cloud Music, QQ Music, Kugou Music, Kuwo Music. Drag a handle, or focus a row and press ⌥ ↑ / ⌥ ↓ (Alt ↑ / Alt ↓ on Windows and Linux), to change the order.

File name pattern

Link to the “File name pattern” section

The default pattern is {艺术家} - {标题} (artist - title). It can use three placeholders, {艺术家} (artist), {标题} (title) and {音轨号} (track number); any other text must match as written. Below the field, a live example shows what the pattern reads, and a pattern that does not work says why while the previous one stays in use. A few common patterns sit next to the field, ready to fill in with one click.
