Add a folder

The library reads music files from the folders you add. Once a folder is added, the app scans it in the background. Scanning only reads files: it never moves, copies or rewrites any of them.

Add a folder

Link to the “Add a folder” section

On the library page, press “Add folder” and pick the folder that holds your music in the system dialog. On the first start the library is empty and the same key sits in the middle of the page.

Compared with the folders already added:

  • The same folder is not added twice; the page says it is already there.
  • A subfolder of an added folder is not added on its own; the page says which folder already contains it.
  • The parent of an added folder can be added: the old subfolder is merged into it, and its tracks keep the time they were added.

Scanning

Link to the “Scanning” section

A scan has two steps. First it finds every file, while the total is still unknown and the bar sweeps the groove. Then it reads the files one by one and shows “scanned / total” and the path being read. “Pause” stops a scan, and “Continue” picks it up where it stopped.

New tracks appear on the library and album pages while the scan runs. Every time the app starts, the library first shows what it had, then quickly rescans in the background, reading only the files that changed.

Which files are added

Link to the “Which files are added” section
Kind Extensions What happens
Audio flac mp3 m4a aac ogg oga opus wav aif aiff ape wv dsf dff mpc tta wma Tags, duration, format and cover are read
Protected ncm qmc0 qmcflac mflac kgm kwm and others Listed and counted, but never opened or decrypted, and they cannot play
Anything else All other files Ignored

Files and folders whose names start with ., files the system marks as hidden and links that point elsewhere are skipped. Folders the app may not read are skipped too, and the scan goes on.

Moving, renaming and going offline

Link to the “Moving, renaming and going offline” section

The library recognizes each track by its audio data, so a track moved between added folders, renamed or retagged is still the same track and keeps the time it was added.

When a folder lives on an external drive that is not connected, the folder is marked offline. Its tracks stay in the library but cannot play for now; the next scan after the drive is back brings them back.

Manage folders

Link to the “Manage folders” section

“Manage folders” on the library page lists the added folders: path, online or offline, number of tracks and when the last scan finished. Each folder can be rescanned or removed on its own. Removing a folder only deletes the library’s records; the files on disk stay where they are.
